# Folio

A browser-based e-book reader built on [foliate-js](https://github.com/johnfactotum/foliate-js).

Live: https://hritikbtw.github.io/epub/

The Linux version of [Foliate](https://github.com/johnfactotum/foliate) uses WebKitGTK, which is unstable and breaks often. So I thought it would be cool that I could open any e-book directly in the browser I daily use.
